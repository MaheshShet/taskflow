# 🚀 Full Stack To-Do App using Spring Boot, Angular, JWT & MySQL

A complete full-stack To-Do application step by step using modern technologies with a clean layered architecture, form validation, pagination, and secure JWT login.

This repository is **public for learning**, but only the owner maintains the code and merges changes.

This project is created as part of the "Coding with Mahesh" YouTube series.
It is intended for educational and learning purposes.

## Tech Stack

- **Java** (JDK 17/21)
- **Spring Boot**
- **Rest API**
- **Spring Data JPA (Hibernate)**
- **Angular**
- **JWT**
- **MySQL**
- **Maven**

---

## Features
- ✅ How to build REST APIs using Spring Boot
- ✅ How to create a frontend using Angular
- ✅ How to implement JWT authentication
- ✅ Login & Authorization (Spring Security)
- ✅ Global Exception Handling
- ✅ DTO + Entity separation (clean architecture)
- ✅ CRUD operations (Create, Read, Update, Delete)
- ✅ Frontend & backend integration
- ✅ Secure routes using JWT
- ✅ Pagination + Sorting
- ✅ Dashboard
